# G1 人形机器人足球颠球任务技术总结

## 1. 任务简述

本项目尝试在 humanoidverse / IsaacGym 框架下构建 G1 人形机器人的足球颠球任务。与普通运动模仿或行走控制不同，颠球任务同时包含机器人自身平衡、球轨迹控制、击球时机判断和动作风格约束，是一个典型的高动态接触控制问题。

在该任务中，机器人不仅需要维持自身姿态稳定，还需要在合适的时机对球进行主动修正，使球尽量保持在身体前方的可控区域内。二者之间存在明显冲突：过强的姿态稳定约束会抑制摆腿击球动作，过强的击球奖励又容易导致机器人牺牲平衡或产生异常姿态。因此，如何在“自身稳定”和“控球修正”之间找到合适的平衡，是该任务的核心难点。

此外，颠球任务还具有较强的稀疏奖励特性。早期训练中，机器人很难自然探索到有效触球行为；即使能够触球，也可能出现粘球、乱踢、侧向飞球、姿态崩坏等问题。因此，该任务不仅需要设计目标奖励，还需要设计合理的课程、接触几何约束和动作风格约束。

## 2. 建模方式探索

### 2.1 手工分阶段建模

最初的思路是基于人的经验，将颠球过程拆分为若干明确阶段，并在不同阶段设置不同的动作奖励。例如：准备、抬腿、击球、收腿、恢复站立等。

这种方式的优点是约束非常明确，机器人较容易被引导到“踢到球”的行为附近；但缺点也非常明显：阶段划分依赖大量人工经验，reward 设计复杂，扩展性差。一旦球的初始状态、速度或落点发生变化，原有的阶段规则就很难继续适配。

因此，这类方法更像是对单次击球动作的强引导，而不是一个真正具备泛化能力的颠球控制器。

### 2.2 基于目标区的门控修正建模

后续将任务重新抽象为“球轨迹修正”问题：机器人不再被要求严格执行某个固定击球流程，而是需要将球维持在身体前方的可控目标区内。当球偏离目标区时，机器人需要通过击球或姿态调整将其修正回来。

在这个建模下，reward 主要分为两层：

第一层是球的功能目标，即球是否位于目标区域内，或是否朝目标区域回归。

第二层是机器人自身约束，即姿态稳定、动作平滑、支撑脚稳定和腿部动作合理性。

这种方式显著简化了任务描述，也比手工分阶段建模更具扩展性。但它带来的新问题是：目标区奖励本身并不能直接诱导机器人完成“主动击球”行为。对于 PPO 来说，如果早期训练几乎没有有效触球样本，那么策略很难从稀疏的目标区奖励中学到“应该抬腿并击球”。

## 3. 关键问题分析

### 3.1 稀疏奖励与触球探索困难

在目标区修正建模下，最直接的问题是奖励稀疏。机器人只有在偶然触球并改变球轨迹后，才能得到较明显的任务收益。早期随机策略几乎无法稳定产生有效触球，因此训练很容易停留在无意义动作或保守站立附近。

为了解决这个问题，我尝试加入脚球距离奖励，使脚部逐渐靠近球，从而提高触球概率。该方法可以在一定程度上改善早期探索，但也引出了新的问题：如果距离奖励过强，策略可能倾向于“贴近球”而不是“击打球”，从而产生粘球、顶球或非预期接触行为。

这说明颠球任务不能只奖励“接近球”，还必须进一步定义什么是有效击球。

### 3.2 Reward 组合导致的局部最优

颠球任务中，不同 reward 项之间存在明显竞争关系。例如，触球奖励过强时，机器人可能牺牲姿态稳定，采取夸张动作去碰球；姿态或动作规范奖励过强时，机器人又可能保持稳定但不愿主动出脚。

即使将部分动作约束设计为 penalty，也无法完全避免这种问题。由于 PPO 只优化总 reward，若某一项奖励在数值上占主导，策略就可能通过极端行为获取高回报，从而忽略其他约束。这类现象本质上属于 reward hacking 或局部最优。

因此，颠球任务的 reward 设计不能只追求“项数完整”，更关键的是各项 reward 的相对尺度、激活时机和门控条件是否合理。

### 3.3 “踢”这个动作本身难以定义

颠球中的“踢”并不是简单的脚部接触球，而是一个具有方向性和爆发性的动作。理想情况下，机器人应通过小腿前摆驱动脚背击球，同时保持脚踝绷直、膝盖朝前、支撑腿稳定。

但这些人类直觉中的动作概念，不能直接由单个关节角度描述。例如，“膝盖朝前”并不是某个单独 DOF 的数值，而是由髋、膝、踝和脚掌空间关系共同决定。

因此，我尝试使用几何向量来描述腿部动作结构：

- 小腿向量：由脚踝指向膝盖；
- 大腿向量：由髋关节指向膝盖；
- 脚掌向量：由脚尖指向脚踝；
- 膝盖方向：由大腿和小腿的几何关系构造，并投影到水平面判断朝向；
- 脚踝姿态：通过小腿向量与脚掌向量夹角约束脚背形态。

相比直接约束关节角度，这种几何建模更接近“腿法”本身，也更容易描述击球时的局部姿态。但它仍然无法完全替代 motion prior，因为自然动作还涉及时序、速度和全身协调。

### 3.4 Motion prior 效果受参考动作质量限制

我也尝试过使用 motion tracking 或动作先验来约束机器人动作，使其击球姿态更加自然。但实际效果受参考动作质量影响较大。

一方面，GVHMR 等视频动作估计工具得到的人体动作在腿部细节、脚踝姿态和接触相位上并不总是稳定；另一方面，从人体动作 retarget 到 G1 后，关节结构、腿长比例、脚部姿态和动力学约束都会发生变化。最终得到的参考动作并不一定适合作为颠球任务的强先验。

因此，motion prior 在该任务中更适合用作弱约束或初始化参考，而不能直接替代任务 reward。后续如果继续推进，可以从更干净的参考动作采集、手工修正关键帧或专门设计无球击球 primitive 入手。

### 3.5 多次颠球的出脚时机判断困难

单次击球已经较难，多次颠球的关键问题进一步变成：机器人必须判断何时出脚。

如果只根据球是否进入“适合出脚的空间区域”来触发击球，并不充分。因为球可能已经处于该区域，但下落速度过大，机器人还没来得及完成摆腿，球就已经落地。即使加入当前竖直速度 `vz`，也只能反映即时状态，不能直接反映未来一段时间的可触达性。

因此，我拓展了 actor observation，通过简单的弹道预测估计球在未来短时间内的位置。例如根据当前位置、速度和重力近似预测 0.5 秒后的球高度，从而为策略提供更直接的击球时机信息。

这类预测观测可以帮助策略从“看到当前球位”升级到“预判球将要到哪里”，对于多次颠球和提前摆腿具有重要意义。

## 4. 阶段性结论

虽然该项目目前仍处于初级探索阶段，尚未实现稳定连续颠球，但整个过程中对人形机器人强化学习任务设计有了更具体的理解。

### 4.1 强化学习更像是在设计规则，而不是写动作脚本

对于机器人强化学习来说，关键不是一步步告诉机器人该怎么做，而是设计一套尽量完整、不容易被钻空子的“游戏规则”。

当规则存在漏洞时，策略不会按照设计者的直觉行动，而是会寻找最容易获得高 reward 的路径。这个路径可能是粘球、乱踢、牺牲姿态稳定，甚至是利用某些接触检测或奖励尺度上的漏洞。

因此，reward 设计的本质不是描述理想行为，而是构造一个优化目标，使得“最优策略”尽可能接近我们真正想要的行为。

### 4.2 不应过度追求一开始就完美的任务描述

颠球任务非常复杂，无法仅凭一个简洁优雅的目标函数就自然学成。高层任务描述可以保持简洁，例如“将球维持在身体前方可控区域内”；但低层训练接口仍然需要针对接触几何、击球时机、姿态稳定、动作平滑等问题逐步补充约束。

这意味着任务设计不可避免会经历从简单到复杂、从粗糙到精细的过程。每一次策略出现异常行为，都能反映当前规则中的一个漏洞。后续优化不是盲目堆 reward，而是判断该问题属于哪一层：目标定义、接触几何、观测信息、动作先验，还是低层控制约束。

### 4.3 当前项目的价值

虽然目前没有得到稳定连续颠球策略，但项目已经完成了以下探索：

- 在 humanoidverse / IsaacGym 中构建 G1 robot + ball 的最小颠球环境；
- 设计球状态观测、脚球距离奖励、接触奖励和目标区修正奖励；
- 尝试手工分阶段建模与目标区门控修正建模；
- 使用腿部几何向量描述膝盖方向、脚踝姿态和击球腿法；
- 拓展 actor observation，引入未来球位预测用于击球时机判断；
- 分析了稀疏奖励、reward hacking、粘球、局部最优和 motion prior 失效等问题。

这些结果说明，该任务的主要瓶颈已经从“环境能否搭建”转向“如何稳定诱导有效击球和连续控球”。后续若继续推进，可以优先从更稳定的单次击球 curriculum、可控无球击球 primitive、接触几何 reward 和更可靠的参考动作先验入手。
